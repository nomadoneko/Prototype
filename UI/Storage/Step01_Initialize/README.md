# Step01_Initialize

## 目的

既存のUndo・Redo機能に初期化機能を追加する。

## 実装

初期化ボタンを追加した。

初期化ボタンから `initializeDrawing()` を実行する。

既存のUndo・Redo機能とUIは残している。

## UI

以下のボタンを配置した。

- Undo
- Redo
- 初期化

## 確認

PCで初期化ボタンを押し、Canvasの描画が消去されることを確認した。

初期化後にUndo・Redoの履歴も消去されることを確認した。

## 問題・未対応

初期化ボタンのUI配置・見た目に問題がある。

現在のUIは使いづらいため、今後UIを整理するときに修正する。

## 結果

機能確認済み。

UIは要修正。
