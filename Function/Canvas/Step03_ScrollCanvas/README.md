# Step03_ScrollCanvas

## 目的

Canvasをスクロールできるか確認する。

---

## 実装内容

- Canvasを `canvasContainer` の中へ配置
- `canvasContainer` にスクロール機能を追加
- Canvasサイズを画面より大きく設定

---

## 確認結果

### 成功

- Canvasをスクロールできた。
- 縦方向のスクロールは問題なく動作した。

### 問題点

- スクロール後に描画位置がカーソルからずれる。
- 描画座標がスクロール量を考慮していない可能性がある。

---

## 今回の結論

スクロール機能自体は実現可能であることを確認できた。

一方で、描画機能と組み合わせる場合は、スクロール後の座標計算を修正する必要がある。
