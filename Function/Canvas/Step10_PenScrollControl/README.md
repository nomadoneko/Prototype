# Step08_MultiCanvasDrawing

## 目的

複数Canvasが独立して描画できるか確認する。

---

## 実装内容

- 各Canvasへ同じ描画処理を登録
- CanvasごとにContextを取得
- Canvasごとに描画状態を管理

---

## 確認結果

### 成功

- 1ページ目へ描画できた。
- 2ページ目へ描画できた。
- 3ページ目へ描画できた。
- 他のCanvasへ影響しなかった。

---

## 結論

Canvasを複数配置しても独立して描画できることを確認した。
