# Step10_PenScrollControl

## 目的

Apple Pencilで描画中だけスクロールを無効化し、Apple Pencilは描画、指はスクロールという操作を実現できるか確認する。

---

## 実装内容

- `pointerType === "pen"` のときのみ描画処理を開始
- Apple Pencilで描画開始時に `canvasContainer` のスクロールを停止
- Apple Pencilで描画終了時にスクロールを再開
- `canvasContainer` を定数として取得し、毎回 `getElementById()` を呼ばないように修正
- テキスト選択・コピー用メニューが表示されないようCSSを追加

---

## 確認結果

### 成功

- Apple Pencilで描画できた。
- 指でスクロールできた。
- 指でタップしても描画されなくなった。
- 描画中に青い選択範囲やコピー用メニューが表示されなくなった。

### 問題点

- 特になし

---

## 結論

Apple Pencilによる描画と、指によるスクロールを両立できることを確認した。

## 備考

- 描画中のみスクロールを停止し、描画終了後にスクロールを再開する方式を採用。
- `pointerType` を利用することで、Apple Pencilと指の操作を適切に分離できた。
