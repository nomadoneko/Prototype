# Step04_ScrollCoordinate

## 目的

スクロール後でも正しい位置に描画できるか確認する。

---

## 実装内容

- 座標取得を `getCanvasPosition()` に変更
- Canvas内部サイズを 2000×3000 に変更
- CSSサイズとCanvas内部サイズを一致させた

---

## 確認結果

### 成功

- スクロール後もカーソル位置に正しく描画できた。
- Step03で発生していた描画位置のずれは解消された。

### 問題点

- 現時点ではPCのマウス操作のみ確認。
- タッチ操作、Apple Pencilは未検証。

---

## 結論

Canvasの内部サイズを表示サイズと一致させ、`getBoundingClientRect()` を利用して座標を取得することで、スクロール後も正しい位置へ描画できた。
