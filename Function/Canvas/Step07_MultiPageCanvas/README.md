# Step07_MultiPageCanvas

## 目的

複数ページ方式のCanvasレイアウトを確認する。

---

## 実装内容

- Canvasを3枚配置
- 1ページ目のみ描画
- ページ間に余白を追加

---

## 確認結果

### 成功

- 複数ページを表示できた。
- 1ページ目へ正常に描画できた。
- スクロールできた。
- ページレイアウトを確認できた。

### 問題点

- 2ページ目以降は描画できない。
- まだ複数ページ管理は未実装。

---

## 結論

複数ページ方式でもレイアウトやスクロールに問題はなく、ノートアプリとして採用できそうである。
