# Step02_ScreenCaptureBasic

## 目的

画面の右半分をキャプチャし、現在Layerへ画像として貼り付けられることを確認する。

また、キャプチャ画像をLayerの履歴に登録し、既存のUndo / Redoで操作できることを確認する。

## 実装した内容

### 画面キャプチャ

`navigator.mediaDevices.getDisplayMedia()` を使用して画面をキャプチャする。

キャプチャした画面の右半分を取得する。

### Layerへの貼り付け

取得した右半分の画像を現在Layerへ貼り付ける。

画像は `image.js` の `addImageToCurrentLayer()` を使用して処理する。

### 画像の履歴登録

キャプチャ画像をData URLへ変換し、`drawingHistory`へ画像データとして登録する。

画像データには以下を保存する。

* `layerIndex`
* `imageData`
* `type: "image"`

### Undo / Redo

キャプチャ画像も通常の描画と同じ履歴システムで扱えるようにした。

以下を確認した。

* Ctrl + Z → キャプチャ画像が消える
* Ctrl + Y → キャプチャ画像が戻る

## 操作

### C

画面キャプチャを開始する。

共有する画面を選択すると、右半分が現在Layerへ貼り付けられる。

### V

現在Layerの表示 / 非表示を切り替える。

### A

全Layerの表示 / 非表示を切り替える。

## 確認結果

PCで確認した。

* 画面キャプチャができる
* 画面の右半分を取得できる
* 現在Layerへ画像を貼り付けられる
* VによるLayer表示 / 非表示ができる
* Aによる全Layer表示 / 非表示ができる
* Ctrl + Zでキャプチャ画像を消せる
* Ctrl + Yでキャプチャ画像を復元できる
* キャプチャ画像が履歴に登録される

## 注意点

画面共有を停止しない状態で再度Cを実行すると、複数のキャプチャ処理が残る場合がある。

これは今回の基本機能とは別のため、必要に応じて後のStepで改善する。

## 次のStepの方針

### Step03：キャプチャ画像の保存・復元

今回追加したキャプチャ画像をlocalStorageへ保存し、ページ更新後も画像を復元できるようにする。

既存のAutoSave機能を利用し、`drawingHistory`に含まれる画像データも保存対象にする。

### 確認すること

1. キャプチャ画像をLayerへ貼り付ける
2. localStorageへ保存される
3. ページを更新する
4. キャプチャ画像が復元される
5. 複数Layerにある画像も復元される
6. 描画と画像が混在した状態でも復元される

### 保存方式

今回は `localStorage` を使用する。

将来的に画像データが増えてlocalStorageでは容量や性能に問題が出る場合は、IndexedDBへの移行を検討する。

### 今回は実装しない

* IndexedDB
* ファイル保存
* キャプチャ範囲の自由選択
* キャプチャ画像の編集
* キャプチャ共有状態の高度な管理

まずは「保存 → ページ更新 → 復元」が正常に成立することを確認する。
