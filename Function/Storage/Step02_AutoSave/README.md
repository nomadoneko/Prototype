# Step02_AutoSave

## 目的

ページを更新しても、保存した描画状態を復元できるようにする。

## 実装

localStorageを使用して描画履歴を自動保存する。

保存対象は `drawingHistory`。

各ストロークについて以下を保存する。

- canvasIndex
- points
  - x
  - y

描画が完了したときに自動保存する。

ページ読み込み時にlocalStorageから描画履歴を読み込み、Canvasを再描画する。

## 保存方法

localStorageを使用。

### その他の候補

#### IndexedDB

大量のデータや構造化されたデータを扱う必要が出た場合に検討する。

#### ファイル保存

データをファイルとして保存・管理する必要が出た場合に検討する。

## 確認

PCで確認。

- 描画後にページを更新しても描画が復元されることを確認
- 複数Canvasに描画した状態も更新後に復元されることを確認
