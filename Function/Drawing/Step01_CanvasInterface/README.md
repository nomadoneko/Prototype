# Step01_CanvasInterface

## 目的

CanvasとDrawingの役割を分離し、
Drawing側からCanvasを利用できる構造を確認する。

## 役割

### canvas.js

Canvas側を担当する。

- Canvas取得
- Canvasサイズ設定
- Canvasのcontext取得
- Canvas座標取得

### drawing.js

Drawing側を担当する。

- ペンによる描画
- pointerイベント
- ペン判定
- 描画中のスクロール制御

## 確認項目

- [ ] 複数Canvasを取得できる
- [ ] 各Canvasに描画できる
- [ ] Apple Pencilで描画できる
- [ ] 指では描画しない
- [ ] 指でスクロールできる
- [ ] 描画中はスクロールしない
- [ ] Canvas側とDrawing側のコードを分離できている
